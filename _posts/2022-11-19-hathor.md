## 1. Executive Summary

Hathor is a complex Active Directory machine running Windows Server 2019 in the `windcorp.htb` domain. The attack path demonstrates a multi-stage compromise involving web application upload filters, AppLocker policy analysis, credential harvesting, DLL hijacking via scheduled SMB execution, code-signing certificate recovery from the Recycle Bin, and Kerberos DCSync ticket forgery.

### Detailed Attack Chain Summary:

1. **Reconnaissance & Perimeter Scanning:** An Nmap scan reveals open ports including DNS (53), HTTP (80), Kerberos (88), RPC (135), SMB (445), LDAP (389), and WinRM (5985).
2. **mojoPortal CMS Extension Filter Bypass:** The web application on port 80 is mojoPortal CMS. Authenticating with default credentials (`admin@admin.com` / `admin`) opens the Admin Dashboard and File Manager. While direct uploads of `.aspx` files are blocked by extension filters, uploading a `.txt` web shell payload and using mojoPortal's internal file copy feature to duplicate and convert `.txt` into `.aspx` bypasses the filter, yielding a reverse shell as `hathor\svc_mojoportal`.
3. **AppLocker Enumeration & Credential Harvesting:** Inspecting the system's AppLocker configuration reveals path rules allowing execution in `C:\share`, `C:\Get-bADpasswords`, and `C:\script`. Uploading Sysinternals `AccessChk` allows inspecting permissions. Searching `C:\Get-bADpasswords` uncovers an audit CSV log file containing the NTLM hash for domain user `BeatriceMill`. Cracking the hash with Hashcat yields password `abceasyas123`.
4. **SMB Share Enumeration & 7-Zip DLL Hijacking:** Authenticating to SMB as `beatricemill` grants access to the `\\hathor.windcorp.htb\share` directory. Directory monitoring reveals a periodic task executing `C:\share\scripts` binaries. The `7-zip64.dll` binary inside `\share\scripts` is missing or writable. Compiling a custom C++ hijack DLL (`7-zip64.dll`) and placing it in `\share\scripts\` triggers DLL execution when the scheduled task fires, delivering a reverse shell as user `GinaWild` and escalation to `SYSTEM`.
5. **Recycle Bin Certificate Theft & Authenticode Hijacking:** Inspecting the `$Recycle.Bin` directory as `GinaWild` reveals deleted PKCS#12 certificate files (`.pfx`). Cracking the PFX password with `crackpkcs12` using `rockyou.txt` recovers the certificate password (`abceasyas123`). The certificate is an active Code Signing Certificate issued to domain administrators for the `Get-bADpasswords` script workflow.
6. **Script Signing & Escalation to bpassrunner:** Modifying `C:\Get-bADpasswords\Get-bADpasswords.ps1` to execute a reverse shell and signing the modified script using `Set-AuthenticodeSignature` with the recovered certificate satisfies the AppLocker and script execution policy. Triggering the script execution via `cscript .\run.vbs` executes the payload as `bpassrunner`, landing a shell as a domain-privileged account.
7. **DCSync & Domain Admin Compromise:** As `bpassrunner`, running `Get-ADReplAccount` performs a DCSync attack against the Domain Controller, dumping the NT hash for domain `Administrator` (`b3ff8d7532eef396a5347ed3393303cb`). A Kerberos TGT is acquired using `getTGT.py` / `kinit`, enabling Evil-WinRM access as `Administrator` on `hathor.windcorp.htb` to retrieve both user and root flags.

### 3.4 File Manager Extension Filter Bypass

To achieve remote code execution, an ASPX web shell must be uploaded to the web directory. A standard ASPX web shell from `jivoi/pentest` repository is selected as the shell payload:

Target web shell URL path on the server:

```

```

Directly attempting to upload `.aspx` files via the File Manager upload form is blocked by extension validation rules.

<img src="assets/img/hathor/Upload_txt_files.png">

The file upload handler validates file extensions during upload, but the file duplication routine fails to enforce extension blacklists when saving copied items.

## 8. Remediation & Security Recommendations

1. **Web Application Extension Blacklisting [Critical]:** Upgrade or patch mojoPortal CMS to enforce strict allowlists for file uploads rather than extension blacklists. Validate file extensions during all file operations including file copies, renames, and moves.

2. **Hardcoded Administrative Credentials [High]:** Change default administrative credentials for mojoPortal (`admin@admin.com`) immediately upon deployment. Enforce strong multi-factor authentication (MFA) for web management portals.

3. **AppLocker Whitelist Overly Permissive Paths [Critical]:** Audit and restrict AppLocker path rules. Remove writable permissions for standard users from whitelisted execution directories such as `C:\share`, `C:\script`, and `C:\Get-bADpasswords`.

4. **Insecure Password Logging & Cleartext Storage [Critical]:** Discontinue the use of custom scripts (`Get-bADpasswords`) that log plain text passwords or NTLM hashes to accessible CSV files. Implement secure Active Directory password policy enforcement using fine-grained password policies (FGPP) or specialized PAM solutions.

5. **SMB Share Write Permissions & DLL Hijacking [High]:** Restrict SMB share permissions on `\\hathor.windcorp.htb\share\scripts\`. Ensure unprivileged users cannot write or overwrite executable files (`.exe`, `.dll`, `.cmd`, `.bat`) in directories scanned or executed by scheduled tasks.

6. **Insecure Storage of Code Signing Certificates [Critical]:** Secure code signing certificates (`.pfx`) in encrypted key vaults or Hardware Security Modules (HSMs). Enforce strong, complex passphrases for all exported PKCS#12 bundles, and ensure deleted sensitive files are securely wiped rather than placed in the `$Recycle.Bin`.

7. **Excessive Replication Privileges (DCSync) [Critical]:** Audit Active Directory permissions for `DS-Replication-Get-Changes` and `DS-Replication-Get-Changes-All`. Remove DCSync rights from non-Domain-Admin accounts like `bpassrunner`.

8. **SMB Message Signing & Kerberos Hardening [High]:** Maintain SMB Signing configuration and implement strict Kerberos pre-authentication policies. Monitor Active Directory replication requests for anomalous DCSync activity.
